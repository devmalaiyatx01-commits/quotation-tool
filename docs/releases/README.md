# Release notes

One file per release to the VM, `YYYY-MM-DD-<slug>.md`, from the template at the end of
[RELEASE.md](../../RELEASE.md). The note holds the plan, the owner's yes (quoted, for that commit),
and the result. [FinalDeployment.md](../../FinalDeployment.md)'s "Deployed" table keeps the one-line
history. Releases before 2026-11-02 are recorded only there.
